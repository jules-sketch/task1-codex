# Buddie Roman Numeral Calculator

A single-page calculator that accepts roman numerals, performs sequential arithmetic, and returns roman numeral answers. The interface uses a monochromatic blue palette so Buddie feels cohesive and calm.

## Getting started

Open `index.html` in any modern browser. No build step or dependencies are required.

## Using Buddie

1. Click roman numeral buttons (or press the matching keyboard key) to enter a value.
2. Choose `+`, `−`, `×`, or `÷`.
3. Enter the next numeral and press `=`.
4. Buddie only works with values between I and MMMCMXCIX (1–3999). Division results are floored to the nearest whole number to keep the output valid.
