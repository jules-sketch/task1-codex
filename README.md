# buddie Roman Numeral Calculator

This is a lightweight in-browser calculator that works entirely with Roman numerals. Every numeric display and keypad entry uses Roman symbols while calculations are performed under the hood to ensure accuracy.

## Features
- **Roman numerals only:** Input using `I, V, X, L, C, D, M` and `N` (zero) with support for negatives via `±`.
- **Accurate math:** Add, subtract, multiply, or divide (integer-only) with clear feedback for invalid or out-of-range values.
- **Blue-themed UI:** A calm monochromatic interface that keeps the focus on your calculations.

## Usage
Open `index.html` in any modern browser to start calculating. The controls include:
- Number keys for Roman numerals and `N` (zero)
- `±` to toggle sign, `AC` to reset, and `⌫` to remove the last character
- Arithmetic operators (`+`, `−`, `×`, `÷`)
- `=` to normalize the current numeral and **Calculate** to evaluate the active expression
